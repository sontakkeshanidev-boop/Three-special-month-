THREE MONTHS — SURPRISE WEBSITE

1. Open index.html in a browser to preview.
2. Tap "Open your surprise" to reveal the page.
3. Tap "♫ Play music" to start the original soft ambient melody (browsers require a tap before audio can play).
4. To publish free: create a GitHub repository, upload index.html, then go to Settings → Pages → Deploy from a branch → main / root. Your public website link will appear there.

Personalize before sharing:
- Edit the text in index.html to add your own real memories and photo captions.
- The memory cards are placeholders; you can replace each .memory card with an <img> tag and a caption.
- The relationship counter starts on 23 August 2026 and updates live.
